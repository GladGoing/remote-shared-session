# 共享会话插件 0.2.3

这是本地运行的 Codex 插件，包含分享/接收技能和 stdio MCP 服务。需要本机 Node.js 24、已登录的 Codex，以及独立运行的共享会话服务。

可从 GitHub 仓库安装，终端执行 `codex plugin marketplace add GladGoing/remote-shared-session`，重启 Codex 后在插件目录的“共享会话 · 本地开发”来源中安装“共享会话”。运行文件已包含在仓库中，无需在接收电脑构建或启动服务端。升级来源使用 `codex plugin marketplace upgrade shared-session-local`。

开发仓库提供本地插件来源 `.agents/plugins/marketplace.json`。安装本插件后新建聊天，说“连接共享空间，服务器域名是你的域名”。插件保存地址并打开网页授权流程，在网页输入管理员提供的共享账号密码，再回 Codex 确认连接。不要在聊天中输入密码。

服务默认地址为 `http://127.0.0.1:8787`。纯域名默认使用 HTTPS，服务器在标准 `443` 提供入口时无需填写端口；其他端口需明确提供。局域网独立部署可提供完整的私有 IP 地址，例如 `http://192.168.1.10:8787`，无需公网服务。连接工具会保存地址，也可手动在用户主目录 `.remote-shared-session/settings.json` 写入 `{"server":"https://YOUR_DOMAIN"}` 后重启插件。授权资料保存于同目录的 `profile.json`，请勿分享该文件。附件默认存放 `Downloads/SharedSessions`。

常用指令：

- 连接共享空间并开启提醒
- 分享当前会话给指定成员，并附上我选择的文件
- 同步已经发布的共享会话
- 查看共享收件箱，读取指定内容，下载指定附件
- 查看或关闭共享提醒

分享先生成私有草稿；用户在网页核对内容和成员，再确认发布。只导出已完成轮次的用户/助手文本，不自动上传目录、推理或工具日志。后续同步由用户发起。

Windows 插件进程保持运行时可发送系统提醒。离线或账号失效时停止实时通知，重新连接后补收。系统免打扰和通知权限会影响横幅显示。提醒只打开网页收件箱，不向空闲聊天注入新消息、不自动执行收到的内容。网页提醒需保持页面打开。

此包不包含服务器账号、数据库或聊天内容。局域网与公网的不同服务实例拥有各自的数据；所有成员连接同一实例即可共享。ChatGPT Work 原生事件订阅尚未接入。
