从 Codex 开始分享

  1. 连接共享空间

    在 Codex 中发起连接，使用网页完成登录授权。

  2. 准备会话与文件

    告诉 Codex 要共享当前会话，并明确选择需要发送的文件。

  3. 核对并发布

    打开草稿链接，核对完整内容和接收成员，再点击确认发布。

  4. 成员读取更新

    成员在自己的 Codex 中读取会话、下载文件。你同步后，他们可继续读取新增内容。
